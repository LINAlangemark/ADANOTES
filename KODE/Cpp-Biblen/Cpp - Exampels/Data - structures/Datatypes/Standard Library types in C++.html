Standard Library types in C++

Containers

Type Description
std::vector<T> Dynamic array that can resize itself
std::list<T> Doubly linked list
std::deque<T> Double-ended queue
std::set<T> Collection of unique sorted elements
std::map<K, V> Collection of key-value pairs, sorted by keys
std::unordered_set<T> Collection of unique elements, hashed for quick access
std::unordered_map<K, V> Collection of key-value pairs, hashed for quick access

Iterators

Type Description
std::iterator Base class for all iterators
std::ostream_iterator Iterator that writes to output streams
std::istream_iterator Iterator that reads from input streams
std::back_insert_iterator Iterator for inserting elements at the end of a container
std::front_insert_iterator Iterator for inserting elements at the beginning of a container
std::insert_iterator Iterator for inserting elements at a specified position in a container

Algorithms

Type Description
std::sort Sorts elements in a range
std::find Finds the first occurrence of a value in a range
std::copy Copies elements from one range to another
std::for_each Applies a function to each element in a range
std::transform Applies a function to each element in a range, storing the result in another range
std::accumulate Computes the sum of elements in a range
std::count Counts the occurrences of a value in a range

Miscellaneous

Type Description
std::pair<T1, T2> Stores a pair of values
std::tuple<Ts...> Stores a tuple of values
std::string Sequence of characters
std::stringstream Stream that reads from or writes to a string buffer
std::chrono::time_point Represents a point in time
std::mutex Mutual exclusion primitive for protecting shared data
std::condition_variable Synchronizes the execution of threads
std::atomic<T> Atomic variable for lock-free concurrent programming
